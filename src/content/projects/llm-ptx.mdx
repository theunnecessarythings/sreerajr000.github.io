This project is a deep dive into the low-level world of GPU programming. The goal was to take Andrej Karpathy's `llm.c` and rewrite the GPT-2 inference implementation from scratch in PTX, NVIDIA's parallel thread execution assembly language.

## Performance

The hand-written PTX version runs approximately **1.1 times faster** than the CUDA version on my system.
