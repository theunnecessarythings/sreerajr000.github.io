This repository provides a collection of popular computer vision models implemented in Rust using the [`tch-rs`](https://www.google.com/search?q=%5Bhttps://github.com/LaurentMazare/tch-rs%5D\(https://github.com/LaurentMazare/tch-rs\)) library, which provides Rust bindings for PyTorch.

## Key Features

  * **Extensive Model Zoo:** A wide range of popular and state-of-the-art computer vision models are available.
  * **Pre-trained Weights:** Easily load pre-trained weights from the Hugging Face Hub for all supported models, allowing you to use them for inference and transfer learning out of the box.
  * **Simple API:** A straightforward and easy-to-use API for model loading and inference.
  * **ImageNet Evaluation Example:** Includes a comprehensive example to evaluate model performance on the ImageNet dataset.

  * **DenseNet** (121, 161, 169, 201)

  * **GoogLeNet**
  * **InceptionV3**
  * **MaxViT**
  * **MNASNet** (0.5, 0.75, 1.0, 1.3)
  * **MobileNetV2**
  * **MobileNetV3** (Small, Large)
  * **RegNet** (Y-400MF, Y-800MF, Y-1.6GF, Y-3.2GF, Y-8GF, Y-16GF, Y-32GF, Y-128GF and X-400MF, X-800MF, X-1.6GF, X-3.2GF, X-8GF, X-16GF, X-32GF)
  * **ResNet** (18, 34, 50, 101, 152)
  * **ResNeXt** (50\_32x4d, 101\_32x8d, 101\_64x4d)
  * **ShuffleNetV2** (x0.5, x1.0, x1.5, x2.0)
  * **SqueezeNet** (1.0, 1.1)

  * **VGG** (11, 11\_bn, 13, 13\_bn, 16, 16\_bn, 19, 19\_bn)
  * **Vision Transformer (ViT)** (ViTB16, ViTB32, ViTBH14, ViTL16, ViTL32)
  * **WideResNet** (50-2, 101-2)

## Usage

To use `tch-models` in your project, add it as a dependency in your `Cargo.toml` file:


<CodeWindow title="Usage" language="toml"
code={`[dependencies]
tch-models = { git = "https://github.com/theunnecessarythings/tch-models" }`}/>

### Example

Here's a simple example of how to load a pre-trained ResNet-18 model and perform inference on an image:

<CodeWindow title="Example" language="rust" 
code={`use anyhow::Result;
use tch::{vision::imagenet, Device, Tensor};
use tch_models::vision::models::{load_model, Model};

fn main() -> Result<()> {
    // Set the device to CUDA if available, otherwise CPU
    let device = Device::cuda_if_available();

    // Load the pre-trained ResNet-18 model
    let (model, mut vs, transforms) = load_model(Model::ResNet18, true)?;
    vs.to(device);

    // Load and preprocess the image
    let image = imagenet::load_image_and_resize224("path/to/your/image.jpg")?;
    let image = image.to_device(device);
    let transformed_image = transforms.forward(&image.unsqueeze(0));

    // Perform inference
    let output = model.forward_t(&transformed_image, false);
    let probabilities = output.softmax(-1, tch::Kind::Float);

    // Get the top 5 predictions
    let top5 = probabilities.topk(5, -1, true, true);
    println!("Top 5 predictions: {:?}", top5);

    Ok(())
}`}/>


## Running the ImageNet Evaluation Example

This repository includes an example to evaluate the performance of the models on the ImageNet validation dataset.

1.  **Download the ImageNet dataset:** You can download the dataset from the [ImageNet website](http://www.image-net.org/).
2.  **Set up the dataset directory:** The example expects the ImageNet validation set to be in a directory named `imagenet`.
3.  **Run the evaluation:**
<CodeWindow title="Run Evaluation" language="bash" code={`$ cargo run --release --example vision -- --model <MODEL_NAME>`}/>

    Replace `<MODEL_NAME>` with the name of the model you want to evaluate (e.g., `AlexNet`, `ResNet18`, etc.).
